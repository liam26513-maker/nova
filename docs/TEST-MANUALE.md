# Verifiche manuali sul tablet

Controlli che i test automatici non possono fare. Ogni PR indica quali punti ripetere.

## Aspetto grafico e livelli (Fase 0, punti 1–4)
- [ ] L'app NOVA si apre senza errori e mostra il nome "NOVA" e due pannelli traslucidi su uno sfondo colorato.
- [ ] Toccando **Massimo**, **Bilanciato** e **Prestazioni** i pannelli cambiano: sfocatura viva, sfocatura più morbida, pannello quasi pieno.
- [ ] Ogni tocco sui pulsanti dà una leggera vibrazione e un piccolo "rimbalzo" del pulsante.
- [ ] Con **Automatico**, dopo qualche minuto di uso normale il livello resta fluido (se il tablet fatica deve scendere da solo).
- [ ] Ruotando il tablet la schermata si adatta senza riavviarsi.
- [ ] Con il tema scuro di sistema attivo, all'apertura NOVA usa il tema scuro.
